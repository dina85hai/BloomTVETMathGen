# Teacher Validation and GO/NO-GO

The app now records the five project validation dimensions:

1. Bloom-level accuracy — target ≥ 4.0/5
2. Misconception realism/effectiveness — target ≥ 4.0/5
3. Difficulty progression accuracy — target ≥ 4.0/5
4. Exam appropriateness — target ≥ 4.0/5
5. Pricing acceptance — target ≥ 60% accepting at least one RM79+ tier

Decision rule:
- 5/5 = STRONG GO
- 4/5 = GO
- 3/5 = ITERATE
- below 3 = PIVOT

The dashboard calculates these values from actual stored teacher feedback rather than demonstration numbers.

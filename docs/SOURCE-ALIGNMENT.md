# Source Alignment

The final consolidated application was reconciled against these supplied sources:

1. `COMPLETE-PROJECT-PROMPT-QGEN.md.pdf`
   - Core product uses C1–C4 only.
   - Three difficulty tiers: Easy, Medium, Hard.
   - Bilingual support.
   - Research-backed misconception targeting.
   - TVET contextualization.
   - Marking scheme and validation-oriented design.

2. `Taksonomi Bloom_ Tahap, Maksud dan Contoh Soalan Matematik - Table 1.pdf`
   - Used for the meanings and action style of C1 Remember/Mengingat, C2 Understand/Memahami, C3 Apply/Mengaplikasi and C4 Analyze/Menganalisis.
   - The reference also describes C5 and C6 generally, but they are intentionally inactive because the core project prompt explicitly limits the product to C1–C4.

## User-directed final-format change

The original project prompt contains an MCQ-oriented example/output structure. The final consolidated application instead uses **subjective / constructed-response only** because that was the user's later explicit requirement. The documentation and UI now state this consistently.
